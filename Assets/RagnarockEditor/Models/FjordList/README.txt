Unity с установленным пакетом Unity UI (uGUI).
Скопируйте Assets/FjordList в проект. Команда Tools → Fjord → Create Scroll List добавляет панель 72 × 48 см в текущую сцену. При запуске появятся демонстрационные строки. Переместите панель перед игроком и при необходимости сохраните её как prefab.
Панель использует ScrollRect. Можно тянуть список и перетаскивать ручку полосы прокрутки. Для XR нужен настроенный XR UI Input Module на EventSystem и луч контроллера с разрешённым UI Interaction. Создавайте панель после подключения XR Interaction Toolkit, чтобы автоматически назначился Tracked Device Graphic Raycaster.
SetTracks(имена) загружает новый список и сбрасывает прокрутку и выбор. On Selected передаёт индекс строки с нуля. Файловый диалог и воспроизведение подключаются приложением.
Модели в Models — отдельный объёмный вариант элементов для собственной сборки. Интерактивная панель использует графику uGUI с фасками и маской отсечения. На превью показаны FBX.
